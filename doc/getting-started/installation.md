# Installation

Add the package to your app:

```yaml
dependencies:
  firebase_messaging_handler: ^2.0.0
```

Then fetch dependencies:

```bash
flutter pub get
```

## Minimum Environment

- Dart `>=3.10.0 <4.0.0`
- Flutter `>=3.38.1`
- Android API 24 or later
- Android `compileSdk` 36 or later
